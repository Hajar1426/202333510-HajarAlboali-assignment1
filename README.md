# Hajar Alboali – Personal Portfolio

## Project Description

This project is a responsive personal portfolio website developed for SWE 363 Assignment 1.

The portfolio introduces me as a Software Engineering student, presents some of my previous university projects, and provides visitors with ways to contact me.

The website was developed using HTML, CSS, and JavaScript and is designed to work on desktop, tablet, and mobile screen sizes.

## Features

- About Me section with a short personal introduction
- Projects section featuring two previous university projects
- Contact information including email, GitHub, and LinkedIn
- Contact form with HTML validation
- JavaScript form interaction
- Responsive layout for desktop, tablet, and mobile devices
- Responsive project images
- Navigation between page sections

## How to Run the Project Locally

No installation or additional dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/Hajar1426/202333510-HajarAlboali-assignment1.git
```

2. Open the project folder in IntelliJ IDEA or another code editor.

3. Open `index.html` in a web browser.

The portfolio can then be viewed locally.

## Responsive Design

The website uses CSS Flexbox, CSS Grid, and media queries to adapt to different screen sizes.

The project cards are displayed side by side on larger screens and stack vertically on smaller screens. The navigation and other page elements also adjust for smaller devices.

The responsive design was tested using Safari and Google Chrome at different browser window sizes.

## JavaScript Functionality

JavaScript is used to provide interaction with the contact form.

When a visitor submits a valid form:

1. The default form submission is prevented.
2. A confirmation message is displayed.
3. The form fields are cleared.

No backend is required for this assignment.
